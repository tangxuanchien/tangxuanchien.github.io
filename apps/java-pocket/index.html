About this appVề ứng dụng

Bring back the feel of classic mobile phones with Java Pocket. Explore a collection of retro handset designs, then run compatible J2ME games in a nostalgic phone interface with an on-screen keypad. Import your own J2ME game files in .jar format, choose a phone model, and use familiar controls such as the D-pad, number keys, and soft keys. You can also adjust the screen size for each imported game and keep your favourites close at hand. FeaturesBring back the feel of classic mobile phones with Java Pocket.
